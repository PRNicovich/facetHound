# Integration release — 2026-09-18

## Display hotfix after source freeze

Reflash display only: the splash animation is confined to rows 0–369, above the
receiving strip at 382–451; title and gem move upward. The loading sprite is freed
before main-view allocation. Mode initialization forces a HUD redraw and retries
failed sprite allocation instead of leaving Static numbers blank. Syntax checked;
on-device visual acceptance remains required. The original source tag is unchanged.

Source tag: `integration-2026-09-18`. Base/display build marker:
`INTEGRATION-RELEASE-20260918`. This freezes source, not hardware certification.

Source release on `repo_cleanup`; upload with Arduino IDE as documented in
FLASHING.md. Use the base and display sources from the same revision. Mast and
usbToUART firmware are unchanged by this release. No UF2 artifacts were built.

## Final behavior

- Classic boots directly to machine status: no splash/model-loading dependency.
  The base restores geometry only when a graphical display requests it.
- Dynamic ↔ Static changes mode in place, keeping the active mesh and RAM cache.
  There is no reboot, geometry reconstruction or mesh transfer for that switch.
  Transitions involving Classic retain restart behavior to free incompatible
  screen buffers; entering Classic still skips the loading/splash sequence.
- Receiving-model progress is drawn off-screen and pushed as one sprite, capped
  at 10 updates/second outside the animated splash. The temporary sprite is freed
  before normal rendering.
- Motor control is unchanged from the user's working trial.

## Release checks and limitations

Changed translation units: Arduino-header syntax checks. Geometry regressions:
four source designs, culet reconstruction, Backgammon bounds/girdle visibility.
No full build, physical upload, timing benchmark, or manufacturing approval.

Hardware cable schematic: `Hardware/pcb/integration/ModuleInterconnect.sch` and
its companion INTERCONNECT.md. Existing PCB routing and historical ZIPs are
untouched. Native Eagle visual/ERC review is still needed before fabrication.

Acceptance trial: power on in Classic; switch Dynamic→Static→Dynamic without a
reset/splash; load a model and watch the receiving bar; verify all module cable
pad numbers against the new interconnect with power disconnected.
